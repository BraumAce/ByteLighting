# 2026.9 期

## 9.3

* [Agent每次接新任务都像新人第一天入职？带你告别“一次性智能”](https://mp.weixin.qq.com/s/AzDms1atG5mRw7vbDnm7Qg)：田倬月（腾讯云开发者）——围绕 Forge Memory 将任务中的设计理由、适用边界和失败经验沉淀为可审阅的项目知识，通过读取与沉淀准入进入后续 AI Coding 任务，并结合代码和验证结果持续校正。

* [Harness Engineering：快手电商用 AI 流水线重塑研发范式](https://mp.weixin.qq.com/s/FPUqOssSU0jUb7lKUZRoCA)：快手技术——以领域知识库、open-door/close-door 对抗式 Agent 和 plan-execute-verify 验收贯通需求、Spec、开发、测试与 Oncall，推动全栈式超级个体和端到端自动交付。

## 9.2

* [一文讲透确定性Harness](https://mp.weixin.qq.com/s/rQYSuTF98-xGcdgGPuNHjQ)：左昊（腾讯云开发者）——以工单审核为例，通过阶段化编排、FlowTracer 全链路留痕、IsFinal 提前终止、统一网关与缓存，把 Agent 的复杂决策约束为可解释、可追溯的确定性流程。

* [AI Agent 应用精细化评测：评测体系设计与工程实践](https://mp.weixin.qq.com/s/5Tvv8g20CybjbT0a7iUfHw)：砚东（AliExpress技术）——围绕商品中心 Agent，将评测从只看最终答案升级为覆盖感知、规划、记忆和工具的白盒体系，并以质量、成本、性能指标、Judge Task、EvalTrace 与真实/Mock 双模式支撑可诊断的平台化迭代。

* [从会用Docker到懂设计：隔离、隐藏与行为限制](https://mp.weixin.qq.com/s/81-li5YG2rAHU1RP-EAZSQ)：码农 SharkChili（写代码的SharkChili）——从联合挂载、chroot、namespace 和 cgroup 拆解 Docker 的文件系统隐藏、进程/网络隔离与资源限制，再以约 100 行 Go 代码和 nginx 部署验证轻量隔离边界。

* [AI 驱动研发体系的实践和思考](https://mp.weixin.qq.com/s/OSYCiNajJw6c5-hGFSAfYw)：默达（大淘宝技术）——以 Price360-KB 为例，借助“Agent + 文件夹 + Git”与项目 Harness 组织业务知识、代码、流程和验证证据，形成可验证、可沉淀的 AI 研发知识飞轮，明确人负责决策、Agent 负责执行。

* [得物小摊 AI Native 演进实录：用 Harness 构建可控 AI 交付](https://mp.weixin.qq.com/s/Jcx_3OABcYwzzxWKFgivOA)：正飞（得物技术）——以多 SKU 订单跨 H5、运营后台、Node 与 Go 运行时的交付为例，用 Version Contract、Execution Boundary、Evidence Gate 和 Repair Loop 把业务不变量、执行边界、验证证据与真实反馈串成可追溯的 Delivery Harness。

## 9.1

* [从 Loop 到 Graph Engineering 的演进思考与实战](https://mp.weixin.qq.com/s/BSCzaVPaX7W5E8vrVrVC0g)：姜剑（飞樰，千问AI平台）——从单 Loop 的 Goodhart 定律、目标盲视、循环冲突和测量衰减问题出发，提出以多层 Loop 互相监督的 Graph Engineering，并用 Anchors、Frozen Nodes、External Judgment 和文本分类实战构建可验证、可纠偏的 Agent 协作闭环。

* [Claude Code vs Codex 记忆体系深度对比](https://mp.weixin.qq.com/s/Y8K5DbluHzUDUO7bwidI5A)：京东云开发者——从记忆分层、持久化、自动整理、跨会话传递和 MCP 扩展等维度对比两者，指出 Claude Code 以自动记忆与 AutoDream 形成闭环、Codex 以 AGENTS.md 声明式契约换取可控性，并提出契约、自动记忆与离线整理融合的混合架构方向。
